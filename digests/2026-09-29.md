## ⚠️ 今の使い方が変わるもの

**① Claude Sonnet 5.5 が追加され、Sonnet 5 は「旧モデル」に移りました**
`claude-sonnet-5-5`。**Claude Code では、これが Sonnet の既定になりました。**
Sonnet 5 自体はまだ使えますが、モデル一覧では旧モデルの欄に移動しています。

| | Sonnet 5 | **Sonnet 5.5** |
|---|---|---|
| 入力 / 出力 | $2 / $10 per MTok | **$2 / $10（同じ）** |
| キャッシュ読み | $0.20 / MTok | **$0.20（同じ）** |
| 文脈 | 100万トークン | 同じ |
| 知識の新しさ | Jan 2026 | **Jun 2026** |
| 引退時期 | 2027年6月30日以降 | 2027年9月28日以降 |

**値段は完全に据え置きで、知識が半年ぶん新しくなっています。**

**② Sonnet 5.5 を API から使う場合、動かなくなる書き方が5つあります**
- **思考を切る書き方が変わりました。** `thinking: "disabled"` ではなく
  `thinking: {"type": "between_tools"}` を使います（考える量が high 以下のとき）
- `tool_choice` の `any` と `tool` が**エラー**になります
- **思考の内容が、モデルだけでなく会話とアカウントに紐づきます**（下記の説明つき参照）
- パソコン操作の古いツールが使えません
- 助言役として Opus 4.8 / Opus 4.7 / Sonnet 5 を指定できなくなりました

**③ auto モードの確認に「今回だけ許す」が増えました**
作業フォルダの外を読むときの確認に、**「はい、ただし次回も聞いてください」**という
選択肢が追加されました。これまでは「一度許すとその後ずっと」でした。

## 今日の変更（説明つき）

### 新しいモデル Claude Sonnet 5.5 が出ました

速度と賢さの釣り合いを取る系列（Sonnet）の新しい版です。

- **値段は Sonnet 5 とまったく同じ**（$2 / $10、キャッシュ読み $0.20）
- **知識が Jan 2026 → Jun 2026 に**新しくなりました
- 100万トークンの文脈、最大出力12.8万トークン

*気になるなら聞けること: 「Routine のどれかを Sonnet 5.5 にしても平気?」*

### 思考の内容が「作ったアカウント」に紐づくようになりました

Sonnet 5.5 が考えた内容（思考ブロック）は、**それを作ったアカウント、
またはそれに紐づくアカウントでしか使えなく**なりました。
別のアカウントがそれを送ると、**API 側が黙って外してから処理します**（エラーにはなりません）。
以前のモデルが作ったものは対象外です。
※ 1つのアカウントで使っている限り、気にする必要はありません。

### コネクタを一括で再接続できるようになりました

`/mcp reconnect all` が追加されました。
**接続に失敗した、または認証が必要なコネクタを、まとめて再試行**します。
あわせて、**再開したセッションでコネクタがまだ接続中だと
「そんなツールはありません」と失敗**していた不具合も直り、最大10秒待つようになりました。

*気になるなら聞けること: 「朝イチで Square が繋がってないとき、これで直せる?」*

### 「話が長すぎます」が、圧縮しても直らない場合に対応しました

会話が長すぎるとき、Claude は自動で要約して圧縮します。
**圧縮してもまだ長すぎる場合、これまではそこで詰まって**いました。
今回から、**直近のやり取りをさらに削って、もう一度圧縮**します。

### 応答が壊れたときの見え方が直りました

通信の途中で応答が壊れると、これまでは

- 「JSON Parse error」のような**生のエラーがそのまま表示**される
- **答えの中に「undefined」という文字が書き込まれる**

といったことが起きていました。今回から、**やり直すか、
「応答が途中で切れました」として報告**されます。
考えている途中でサーバー側のエラーが来た場合も、やり直すようになりました。

### `/loop` の進行状況が見えるようになりました

`/loop`（同じ作業を繰り返す機能）の自分でペースを決めるモードで、
**Claude が状況を思考の中にしか書かず、画面に出ていない**ことがありました。
今回から、**各回の状況と、止まったときの結果を必ず文章として書き出します**。

## 一行で流すもの（80件）

**追加されたもの**
- 接続口の利用額の上限が、金額で表示されるように（「$271.40 / $500.00」のような形）
- 考える量のスライダーのキー操作を割り当て直せるように
- `/rate-limit-options` が一覧に載るように（上限の案内から辿れるようになりました）
- 接続口向けの設定4件（起動時の警告、記録の送信先、認証方式）

**直った不具合**
- 使えるモデルが無くなったとき、案内が素っ気ないメッセージになっていた
- 開発キット経由で、壊れた画像や文書が含まれると落ちる／以降ずっと失敗する
- 利用状況の問い合わせが、断られたあとも繰り返されていた
- **`claude mcp add` が、管理設定で禁止されていても「成功」と報告**していた
- `/plugin` の設定画面の入力方法が改善（真偽値、数値、矢印キー）
- 第三者クラウドの接続先の指定が、検証されずに使われていた
- デスクトップで、接続口経由だと100万トークンの選択肢が出なかった
- シェルモードで下矢印を押すと、入力の編集ができなくなっていた
- Windows で、プラグインが多いとコマンドが失敗していた
- 一部の配布元が、古い git だと空で取得され、手元の写しを壊していた
- 全画面表示の不具合（画面消去、スクロール位置、タブの折り返し、件数表示）
- キー割り当てまわりの不具合（3件）
- 画面の切り替え直後のキー入力が、確認を先に答えてしまっていた
- 信頼の確認画面が、更新後に2回出ることがあった
- **`.claude/rules` に外から張ったリンクが、承認を出さずに飛ばされて**いた
- **プラグインが自分のツールを勝手に事前承認**していた（公式・組織が認めたもの以外は不可に）
- プラグインの初回導入が失敗しても、有効として記録されていた
- 確認処理の失敗が、記録に残らないことがあった
- 確認処理からの「拒否」の指示が無視されていた
- メッセージ送信の機能が無いのに、使うよう案内されていた
- アプリから送った写真が、編集のために引き戻すと消えていた
- 上限待ちの最中に入力すると、自動継続の設定から外れていた
- 上限の警告が、最上位プランの人にも「アップグレード」を勧めていた
- **調査用の作業係が、認識できないモデル名だと勝手に Opus に切り替わって**いた
- `/ultrareview` が、デスクトップアプリが作った作業用フォルダから失敗していた
- 隔離環境のコマンドが、権限の組み合わせで起動できなかった
- 成果物のデータ書き込みの説明が誤っていた（誰に見えるか）
- 接続口が、所属グループの多い利用者のリクエストを全部拒否していた

**変わった挙動**
- 上限待ちの表示が1か所にまとまり、繰り返さなくなりました
- Chrome 連携のツール名のエラーが、正しい名前を出すように
- 監視ツールの表示が、実際の出力を出すように
- 起動時間とメモリ使用が改善（設定の読み込み方を変更）
- `/claude-api` の調整機能が改善
- 各種一覧の桁揃えが改善
- 配布元の追加が、既存のものを置き換える場合に知らせるように
- 開発ツール拡張向け18件、ターミナルの vim 操作2件（省略）

**ドキュメント**
- Sonnet 5.5 の解説・移行案内・書き方のコツのページが追加
