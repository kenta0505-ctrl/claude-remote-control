## ③ 今日の変更（説明つき）

### コネクタが「ツールが無い」状態に最大1日ハマるのが直りました

Square や Gmail のようなコネクタ（MCP 接続）が、相手サーバー側の接続方式が古いやり方をやめた直後に、**ツールを一つも認識しない状態が最大1日続く**ことがありました。これが直りました。

「繋がっているのに何もできない」という症状だったので、Routine が黙って空振りしていた可能性のある種類の不具合です。

気になるなら聞けること: 「最近、Routine が動いたのに何もしなかった日ってあった?」

### 秘密情報のマスク漏れが、今日も5件直りました

ログや記録に APIキー・パスワードがそのまま残ってしまう穴の修正です。今日直ったのは以下の5つです。

1. キー名の**前**に "Bearer" や "Basic" という語があると、値が隠されずに出ていた
2. URL用にエンコードされた（`%20` のような形の）Bearer トークンが、一部しか隠れていなかった
3. キー名の中に**目に見えない文字**（ゼロ幅スペースなど）が混ざっていると、マスクをすり抜けていた
4. URL の中のパスワードに `)` `"` `]` `&` や2個目の `@` が入っていると、途中までしか隠れなかった。`[::1]` のような書き方のホスト名でも同様
5. `/feedback` が保存する zip の中の会話記録が、マスク処理の後で壊れた形式（読めない JSON）になっていた

この修正は8月末からほぼ毎日続いています。原さん自身が何かする必要はありませんが、「一度出てしまったログは後から直らない」という性質のものです。

### 履歴が非常に大きいクラウドセッションが目を覚まさなくなる不具合

claude.ai/code のセッションで、会話履歴がとても大きい場合に、**読み込みの途中でコンテナ（実行環境）が止められてしまい、そのまま二度と起動しない**ことがありました。これが直りました。

この digest セッションのように長く続くセッションが、まさにこの条件に当たります。

### モデルが拒否されたとき、1回だけ前のモデルで再試行するようになりました

指定したモデル（またはモデルの別名）が API 側で拒否されると、**そのセッションの全ターンが失敗し続ける**状態になっていました。今は同じ階層の一つ前のモデルで1回だけ再試行します。

あわせて、フォールバック（代替モデルへの切り替え）でコンテキストウィンドウ（一度に扱える文章量の上限）が 100万トークンから 20万トークンに下がった場合、その事実が通知に書かれるようになりました。

### サブエージェントの画面で `/compact` や `/clear` を打つと、本体の会話に効いてしまう問題

サブエージェント（本体の会話とは別に動く作業係）やチームメイトの記録画面を見ている最中に `/compact`（会話の要約圧縮）`/clear`（履歴消去）`/rewind`（巻き戻し）を打つと、**黙って本体の会話に適用されていました**。今は「どちらに効かせるか」を名指しした確認ダイアログが出ます。

`/clear` が意図せず本体に効いていた場合、履歴が消えるので取り返しがつかない種類の事故でした。

### `verify` という名前のスキルがあれば、コミット直前に必ず実行されるようになりました

プロジェクトまたはユーザーのスキル（Claude に持たせる手順書）の中に `verify` という名前のものがあると、Claude Code はコミットの直前にそれを実行するよう指示されます。ドキュメントだけ・テストだけの変更のときは除外されます。

### Remote Control（遠隔操作）まわりで3件

- 組織のポリシーで Remote Control が **オフにされた後も接続が続いていた**。今は通知を出して切断します。
- 送ったファイルが**届かなかったことが Claude に伝わっていなかった**。また、最後のダウンロード試行に10秒しか与えられないことがありました。
- Claude Code が終了しようとしている最中に届いたメッセージが、**「配達済み」と記録されたまま永久に返事が来ない**状態になっていました。今は次回起動まで待機します。

## ④ 一行で流すもの

Claude Code 2.1.286 の残りです。判断は原さんに委ねます。

**セッションの復帰・接続**
- `claude --resume` / `--continue` で、前回が異常終了していた場合に「並列ツール呼び出しの後の全ターン」が消えることがあったのを修正
- ツールやフックが文字列でなく数値・真偽値・オブジェクトを返すと API 400 エラーになっていたのを修正（再開セッションも含む）
- gcpAuthRefresh / awsAuthRefresh の資格情報が切れたとき、プロセスと IDE 拡張がそれぞれログイン用ブラウザを開いていたのを修正
- macOS で、別ウィンドウの `/login` が成功しても `~/.claude/.credentials.json` の残骸があると「未ログイン」表示が続いたのを修正
- ヘッドレス（画面なし）セッションで、MCP 再認証が成功した後も「認証が必要」の催促が繰り返されていたのを修正
- 失敗した API リクエストの再試行の数え方を変更。1回のモデル呼び出し全体で1つの上限になり、既定設定では最大14リクエスト
- 拒否時と `--fallback-model` の再試行が、代替モデルが高速モードに対応していないと失敗していたのを修正（標準速度で実行し、1回だけ通知）

**認証・課金の表示**
- Claude アプリ用ゲートウェイ（社内で API 呼び出しを中継する仕組み）の利用額計に2つの誤り。1時間キャッシュ書き込みを安い5分料金で計算していた点と、Web検索などサーバー側ツールを使うストリーミング応答で最初のモデル呼び出しの入力トークンだけを数えていた点
- `claude auth status` が、Console でサインインして保存した APIキーを `claude.ai` と表示していたのを `api_key` に修正
- `/status` が、APIキーと並んだ Anthropic プロファイルを両方有効のように見せていたのを修正（使用されていない旨を明記）
- `/usage` が、接続中または接続直後の MCP サーバーへのツール呼び出しを、そのサーバーの実績に数えていなかったのを修正
- ゲートウェイが `/protocol` で配る仕様ページを、現在 Claude Code が送る内容に合わせ、「未知の入力を拒否しないこと」と明記

**MCP・プラグイン**
- Claude からの MCP 再サインイン要求が、保留中のサインインリンクを差し替えてしまい、そのリンクが使えなくなることがあったのを修正
- claude.ai で有効にしたプラグインが、一時的なサーバーエラーの後に1セッションだけ Claude Code から消えることがあったのを修正
- 読み込めないマーケットプレイスのプラグインエラーが「見つかりません」でなく、理由と対処を示すようになった
- `/plugin` の Discover タブの「新しいプラグインを確認中…」行で、マーケットプレイス名だけ引用符が付いていなかったのを修正
- プラグインのインストールで、git リポジトリやフォルダを指す npm ソースを拒否し、依存パッケージはレジストリからのみ取得するよう変更
- SDK と `-p` セッションで、既に接続済みのサーバーに対して再度「有効化」が送られたときの応答性を改善

**サブエージェント・バックグラウンド**
- 実行中のサブエージェントに打ったメッセージが、読み取り後に記録に2回表示されていたのを修正
- サブエージェントの引き継ぎメッセージが、名前未登録のとき内部のタスクIDを表示していたのを修正
- 前面で動くサブエージェントが、有効なはずのタスク管理ツール（TaskCreate/Get/Update/List、TodoWrite）を持たないことがあったのを修正
- worktree 分離（作業用の別フォルダ）で起動したサブエージェントが、最初のファイル読み取り時に CLAUDE.md を2回読み込んでいたのを修正
- Workflow ツールのサブエージェントが、応答中に数分の通信停止があると元のプロンプトから再実行されていたのを修正
- バックグラウンドのジョブが、承認待ちの間に「完了」と表示されていたのを修正
- サブエージェント画面での ctrl+enter（すぐ送る）が、実行中のコマンドをバックグラウンドに回してメッセージを即読ませるように変更
- バックグラウンドのエージェントの返答が、冒頭でこちらの発言を要約し直さなくなった
- スキル自身のシェルコマンドも、ctrl+enter で終了させずバックグラウンドに回すよう変更
- 1ターンだけのモデルフォールバックで、コミット署名の注意書きがツール出力の中に再送されていたのを修正

**権限プロンプトの見た目**
- 権限要求が複数溜まったとき「5件中2件」のような件数表示が付いた
