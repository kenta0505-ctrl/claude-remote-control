## ③ 今日の変更（説明つき）

### HIPAA 設定のドキュメントが新設されました

**HIPAA** はアメリカの医療情報保護の法律です。**PHI（protected health information、保護対象の医療情報）** を扱う組織が、Anthropic と **BAA（Business Associate Agreement）** を結んだうえで有効にする、Claude Enterprise プランの組織設定です。

対象は **Claude Code（ローカルモード）と Cowork（ローカルモード）**。「ローカルモード」とは、クラウドセッションではなく手元で動くセッションのことで、具体的には ①ターミナルの Claude Code ②Claude デスクトップアプリの Code タブ ③Claude デスクトップアプリの Cowork の3つです。**VS Code と JetBrains の拡張はローカルモードに含まれず、BAA の対象外**と明記されています。

**適用すると止まる・変わる機能**（ドキュメントの表そのままです）

| 開発者が気づくこと | 理由 |
|---|---|
| WebFetch ツールが使えない | WebFetch がオフ。**Web検索は引き続き使える** |
| `--cloud`、`/teleport`、Remote Control が拒否される | クラウドセッションと Remote Control がオフ |
| `/feedback` と `/bug` が使えない | フィードバック送信がオフ |
| Claude がアーティファクトを公開できない | アーティファクトの公開がオフ |
| `ANTHROPIC_API_KEY` を読む MCP サーバーやフックが認証できなくなる | Claude Code が起動するプロセスから Anthropic の資格情報を外す |
| 別の組織に `/login` し直しても制限が残る | HIPAA 状態は Claude Code を再起動するまで続く |

もう1つ、重要な注意がドキュメントに書かれています。**HIPAA 設定が外すのは Anthropic 向けの資格情報だけ**で、クラウドプロバイダや GitHub の資格情報は外しません。つまり **GitHub に push するコマンドや他のサービスを呼ぶコマンドは今まで通り動き、そこに送ったデータは BAA の対象外**です。

また、HIPAA 設定が効くのは「**Claude Enterprise アカウントでサインインし、Claude Code が Claude API に直接つながっている**」セッションだけです。Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude apps gateway、LLM ゲートウェイ、`ANTHROPIC_BASE_URL` を自前で指定した接続、Console の APIキー経由などは **対象外**（「No」の行）と表になっています。

### モデル一覧の API に `line`（モデルの系統）が追加されました

`GET /v1/models` と `GET /v1/models/{model_id}` の応答に、**`line` という項目**が増えました。そのモデルがどの系統に属するかを返します。

- 例として、**Claude Opus 4.5 と Claude Opus 4.6 はどちらも `opus` を返す**と書かれています。
- どの系統にも属さないモデルは `line` が **`null`** になります。
- ドキュメントは「**モデルの `id` から推測せず、`line` を読むこと**」と明記しています。また「**Anthropic は系統を追加する可能性があるので、値の集合が固定だと思わないこと**」とも書かれています。

モデル選択画面でモデルをグループ分けする、といった用途を想定した項目です。

これは **Platform リリースノートでは10月1日付**になっていますが、今日の取得で初めて資料に現れました。公開から資料への反映に数日のずれがある、という例です。
