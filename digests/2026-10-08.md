### 3. Claude Haiku 4.5 向けに書いたコードは、Haiku 5.5 で壊れることがあります

Anthropic 自身が「**Code written for Claude Haiku 4.5 can break on Claude Haiku 5.5**（Haiku 4.5 向けに書いたコードは Haiku 5.5 で壊れうる）」と明記しています。具体的に挙げられている3点です。

- **手動の拡張思考（`budget_tokens`）は 400 エラーを返す**ようになりました
- **適応思考（adaptive thinking）が既定でオン**なので、応答が `thinking` ブロックから始まることがあります
- **同じ文章がより多くのトークンとして数えられます**

移行ガイドと、Haiku 5.5 向けのプロンプト作法のページが用意されています。

### 4. Managed Agents で、ネットワークが `limited` の環境の制限が Web ツールにも及ぶようになりました

Claude Managed Agents（Anthropic 側で動かすエージェント）で、ネットワークが `limited` の環境は、**その `allowed_hosts` を `web_search` と `web_fetch` にも適用する**ようになりました。

- `allowed_hosts` に一致しないホストの URL への `web_fetch` は、エージェントに `url_not_allowed` エラーを返します
- `web_search` は、そうしたホストの結果を省きます
- **`allowed_hosts` にホストが一つも無い場合、どちらのツールもページも検索結果も返しません**
- `allow_package_managers` と `allow_mcp_servers` は、これらのツールにホストを追加しません
- `unrestricted` のネットワークと自己ホスト環境は、これらのツールを制限しません

**セッション作成が 400 エラーで失敗する条件**も追加されました。`limited` ネットワークで、有効な Web ツールの `allowed_domains` に `allowed_hosts` の範囲外の項目があるとき、セッションの作成（および、そうした項目を追加するセッション更新）が失敗します。

重要な注意: **`allowed_hosts` の項目は、`*.` で始まらない限り1つの正確なホストにしか一致しません。** つまり `docs.example.com` は `["example.com"]` の範囲内ではありません。

### 5. Project Glasswing の提供条件の書き方が変わりました

Claude Mythos 系（Mythos 5 / 5.1）の「限定提供」の説明が書き換わりました。

- 旧: 「**Project Glasswing** の一部として、招待制で個別に提供。アクセスは Anthropic / AWS / Google Cloud の担当チームに連絡」

リンク先も `anthropic.com/glasswing` から Help Center の記事に変わっています。**「招待制」から「認証プログラムへの申請制」へ、入口の性質が変わった**という読み方ができます。
