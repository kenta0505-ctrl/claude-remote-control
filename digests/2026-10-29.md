### プラグインの配布元の説明から「デモ用」が消えました

Claude Code のドキュメント目次の、`plugins/anthropic-marketplaces` のページの説明文が書き換わりました。

- **旧**: 「Claude Code のための Anthropic の**公式・コミュニティ・デモ**のプラグインマーケットプレイス: その名前、リポジトリ、それぞれの追加方法、そしてプラグインを閲覧できる場所」
- **新**: 「Claude Code のための Anthropic の**公式とコミュニティ**のプラグインマーケットプレイス: その名前、リポジトリ、それぞれの追加方法、そしてプラグインを閲覧できる場所」

プラグイン = Claude Code に機能を足す部品。マーケットプレイス = その部品の配布元の一覧です。

**「デモ用のマーケットプレイス」が説明から外れました。** 残っているのは公式とコミュニティの2つです。

**ただし、確認した範囲では「ページが消えた」わけではありません。** 目次の URL を前日と比べたところ、**増減はゼロ**でした。変わったのはこのページの説明文だけです。**デモ用のマーケットプレイス自体がなくなったのか、説明から省かれただけなのかは、この目次だけでは分かりません。** ページの本文を読まないと断定できないので、ここでは断定しません。

### コードを実行するツールの説明の、リンク先の呼び方が変わりました

Platform のリリースノートの、`code_execution_20260120`（Claude がコードを実行するツールの、状態を保ち続けられる版）についての項目です。

- **旧**: 「…コード実行ツールの **[Compatibility（互換性）]** のセクションを参照してください」（リンク先: `#compatibility`）
- **新**: 「…コード実行ツールの **[API support（API の対応状況）]** のセクションを参照してください」（リンク先: `#availability-feature-support`）

**リンク先のページの見出しが「互換性」から「API の対応状況」に変わったので、リンクの文言もそれに合わせた**という変更です。**項目の内容（どのモデルで使えるか、ベータヘッダが不要であること）は一字も変わっていません。**

### 価格表に、モデル ID が1つ書き足されました

- **旧**: 「Claude 4.7 以降のモデルと **Claude Mythos Preview** は、同じ文章について以前のモデルより約30パーセント多いトークンを生成する、新しいトークナイザを使います」
