## ③ 今日の変更（説明つき）

### 会社が社員全員の Claude Code の設定を、部署ごとに分けて配れるようになります

Claude Code には「会社側が決めて、個人には変えさせない設定」（管理設定）という仕組みがあります。これまでは会社に1セットだけでした。今回、**部署やチームの単位（RBAC グループ＝権限をまとめた社員のグループ）ごとに別々の設定を配れる API** のドキュメントが公開されました。グループには優先順位があり、社員が複数のグループに入っている場合は上位のグループの設定が当たります。どのグループにも入っていない人には「既定の設定」が当たります。

これは **Claude Enterprise 契約の会社だけが使えるベータ**で、専用のヘッダー（`anthropic-beta: ce-claude-code-managed-settings-2026-10-06`）を付けないと 404 が返ります。個人や Pro/Max の契約には出てきません。tsubu. の運用には関係しない領域ですが、落とさず書いています。
