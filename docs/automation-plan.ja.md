# 自動化タスクの割り振り表

「どのタスクを、どのツールで自動化するか」の判断記録。タスクが増えたらこの表に追記する。

## 判断ルール（上から順に検討する）

1. **コネクタ（API）があるか？** → あれば必ずコネクタ。速く、安く、壊れない
2. **無いなら、ブラウザで完結するか？** → Claude in Chrome（Cowork サイドパネル）
3. **ブラウザでも届かないか？** → Computer use（画面操作）。最後の手段

出典: [Claude Code Desktop / When computer use applies](https://code.claude.com/docs/en/desktop)

## タスク一覧

| タスク | API/コネクタ | 採用する手段 | スキル | 状態 |
| --- | --- | --- | --- | --- |
| note の記事作成・投稿準備 | **無い**（note に公式APIなし） | 素材取得は Drive コネクタ → 執筆 → **Chrome で下書き保存まで** | `note-article` | 設計済み |
| （レポート作成） | 未確認 | データ元を確認してから決定 | — | 保留 |

## note を Chrome でやる理由

note には**公式の投稿APIが存在しない**。内部エンドポイントを直接叩く非公式な方法は
存在するが、予告なく仕様変更されるうえ公式サポート外で、自動投稿は推奨されていない。
したがって「ログイン済みのブラウザで、人間と同じ手順で操作する」＝ Claude in Chrome が
正しい手段になる。これは判断ルールの 2 番に素直に当てはまるケース。

**公開ボタンは押させない。** 下書き保存で止めて、公開は人間が判断する。
自動化の価値は「書く・貼る」の手間を消すことにあり、公開判断まで渡す必要はない。

## スキルの置き場所に注意

Cowork セッション（Chrome サイドパネルを含む）とクラウドセッションは、
**あなたのPCの `~/.claude/skills/` を読まない。** claude.ai アカウントで有効化した
スキルを、セッション開始時に同期して読み込む。

したがって `skills/` 配下のスキルは:

1. Desktop アプリのサイドバー **Customize**、または claude.ai のスキル設定から**アップロードして有効化する**
2. 有効化すれば Chrome サイドパネル・デスクトップ・モバイルのどこでも同じスキルが効く

出典: [Skills in Cowork and cloud sessions](https://code.claude.com/docs/en/skills)

claude.ai にアップロードするスキルのフロントマターは、仕様の6項目
（`name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`）
だけにする。それ以外のキーを書くと検証エラーになる。

## 定期実行

手順が固まったら、繰り返し実行の仕組みに載せる。

| | クラウド Routines | Desktop ローカルタスク | `/loop` |
| --- | --- | --- | --- |
| PCの電源 | 不要 | 必要（起動＋スリープしない） | 必要 |
| ローカルファイル | 不可 | 可 | 可 |
| 最短間隔 | 1時間 | 1分 | 1分 |

note の投稿準備は**ブラウザとログイン状態が要る**ので、クラウド Routines には向かない。
Desktop のローカルタスク、または手動で都度実行する。
