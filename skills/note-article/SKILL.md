# note 記事の作成と投稿準備

素材を記事に変換し、note のエディタへ入力して**下書き保存**するまでを担当する。

## 絶対に守ること

1. **「公開」「公開設定」ボタンは押さない。** 下書き保存で必ず停止し、人間に確認を求める。
2. **有料設定・予約投稿・マガジン追加を勝手に行わない。** 指示があった場合のみ。
3. **他者のコンテンツを素材にする場合は、要約・自分の言葉での再構成にとどめる。** 原文の長い引用が必要なときは引用範囲を明示し、出典を本文に記載する。素材元の利用規約に反する疑いがあれば、作業を止めて確認する。
4. 事実・数字・固有名詞は素材にある通りに書く。素材に無い数字を創作しない。

## 手順

### 1. 素材を集める

- 素材の場所を確認する（Google Drive のファイル、URL、チャットに貼られたテキスト）。
- Google Drive にあるなら **Drive コネクタで読む**（ブラウザで開くより速く確実）。
- URL なら Chrome で開いて本文を読む。
- 素材が特定できないときは、ここで質問して止まる。推測で書き始めない。

### 2. 記事を書く

デフォルトの構成（指示があればそちらを優先）:

| 部分 | 内容 |
| --- | --- |
| タイトル | 32文字以内。数字か具体的なベネフィットを入れる。煽り表現は使わない |
| 導入 | 3〜4行。誰の何の悩みに答える記事かを明示 |
| 本文 | H2 見出しで3〜5ブロック。1ブロック300〜500字 |
| まとめ | 箇条書きで3点 |
| CTA | 指示があれば末尾に1つだけ |

文体ルール:

- です・ます調。1文は60字以内を目安に切る。
- 専門用語は初出で一度だけ説明する。
- 見出しは体言止めではなく、内容が分かる文にする。
- 「〜と思います」「〜かもしれません」の多用を避ける。断定できることは断定する。

**書き上げたら、note に入力する前に本文をチャットに出して確認を取る。**

### 3. Chrome で note に入力する

1. `https://note.com/notes/new` を開く（またはヘッダーの「投稿」→「テキスト」）。
2. **入力の前に、必ずページを読んで現在の状態を確認する。** 前回の下書きが残っている、ログアウトされている、UIが変わっている、といったことがある。想定と違えば止めて報告する。
3. タイトル欄にタイトルを入力する。
4. 本文欄に本文を入力する。見出しは note のエディタの見出し機能（H2/H3）を使う。Markdown 記法はそのまま文字として残るので使わない。
5. 入力後、**画面を読み返して、本文が最後まで入っているか確認する**。note のエディタは長文の貼り付けで末尾が欠けることがある。欠けていたら不足分を追記する。
6. 「下書き保存」を押す。
7. 保存された下書きの URL を報告する。

### 4. 報告する

- 下書きの URL
- タイトル、文字数
- 人間に判断してほしい点（タグ、見出し画像、公開タイミング）

## 見出し画像とタグ

指示がない限り、**見出し画像は設定しない**（画像の選択は人間の判断に任せる）。
タグは記事内容から3〜5個を提案し、チャットで確認を取ってから入力する。

## うまくいかないとき

- **ログイン画面が出た**: 止めて人間にログインを依頼する。認証情報を入力しようとしない。
- **エディタが反応しない**: ページを再読み込みして1度だけやり直す。それでもダメなら本文をチャットに出力し、手動貼り付けを依頼する。
- **本文が途中で切れる**: 見出しブロック単位に分けて入力する。
